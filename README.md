# Analysis of the paper for EZGI 
# (Efficient splitting of generic barcodes)

<img src=https://github.com/tstohn/Analysis-EZGI/blob/master/docs/media/EZGI_ANALYSIS.png width="200" />


This repository contains the code to run the analyses for the paper of ESGI. More specifically it contains:
 - scripts to run ESGI to the protein and RNA dataset of SIGNAL-seq as well as the scripts to run kITE and zUMI.
 - scripts to run ESGI on the protein and RNA datasets of Phospho-seq as well as the scripts to run Alevin and Cell Ranger.
 - scripts to run ESGI on the xDBiT dataset (we did not run the xDBiT-toolbox itself but used to count matrices deposited in their repo)

This repository mainly serves to store the analysis scripts for the publication.
For further examples and guidelines how to run ESGI please visit https://github.com/tstohn/SCDemultiplexingPipeline and https://tstohn.github.io/ESGI.documentation/
